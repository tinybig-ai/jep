## Home Assistant and Telegram

Thanks to **Alberto Xamin (@albertoxamin)** for contributing the Home Assistant
integration, Telegram forum topics, file delivery and permission recovery in
[PR #23](https://github.com/tinybig-ai/jep/pull/23).

- Install Jep from the Home Assistant app store using this repository URL.
  The sidebar uses HA ingress; Telegram and direct gateway clients are optional.
- Prebuilt amd64 and aarch64 images are available as
  `ghcr.io/tinybig-ai/amd64-jep:0.3.0` and `ghcr.io/tinybig-ai/aarch64-jep:0.3.0`.
- Telegram conversations can live in separate forum topics. `/new` preserves the
  previous topic's history, draft IDs survive restarts and Stop targets its draft.
- `jep-send` returns documents and images to Telegram, web and native clients.
- Permission requests missing from OpenCode's event stream are recovered for
  each subscribed client. GitHub authentication no longer blocks HA startup.
- Upstream tools and fixes include `jep-read`, `jep-tell`, broader model discovery,
  restart recovery, and freeing stuck tool processes.
- Codex runtime instructions are filtered out of conversation history and live
  replies. Namespaced model ids retain their full value when sent to a harness.

## Downloads

- **Android:** install `jep-0.3.0.apk`.
- **macOS:** unzip `JepBar-0.3.0.zip`; first launch uses right-click → Open.
- **Daemon:** `npm install -g https://github.com/tinybig-ai/jep/releases/download/v0.3.0/tinybig-ai-jep-0.3.0.tgz`.
  npm registry publication is separate and requires publisher credentials.
- **iOS:** build from source in Xcode; no TestFlight or App Store distribution yet.

## Upgrading Home Assistant

Update within the same HA repository to retain the app identity and `/data`.
Existing Alberto fork users can continue using that fork; adding the upstream
repository creates a separate HA app and does not automatically transfer data.
See [the HA guide](https://github.com/tinybig-ai/jep/blob/v0.3.0/homeassistant/DOCS.md)
for options, ingress authentication and backup/migration details.
