## Home Assistant installation fixes

- Home Assistant images include the version, architecture and app metadata used
  by Supervisor.
- Agents can run the bundled `jep-*` commands directly.
- OpenCode credentials dropped in the HA configuration share are loaded on startup.
- Configured pairing codes accept hyphens, spaces and lowercase letters.
- CI boots both images with default options before publishing, checks the web
  client and pairing, and verifies conversation and file persistence after restart.
- The one-command installation guide uses the published GitHub tarball, so it
  does not depend on npm registry publication.

Thanks to Alberto Xamin (@albertoxamin) for the Home Assistant integration.

## Install

Home Assistant: add `https://github.com/tinybig-ai/jep` to the app store, install
Jep, enter your model provider credentials, and open the sidebar. GitHub and
Telegram credentials are optional.

Daemon: `npm install -g https://github.com/tinybig-ai/jep/releases/download/v0.3.1/tinybig-ai-jep-0.3.1.tgz`.

Android: install `jep-0.3.1.apk` from this release.

iOS distribution remains through Xcode. Its separate CI work is deferred.
