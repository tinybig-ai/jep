# v0.5.0

The web client gets searchable models, switchable themes and a steadier live
transcript. Keep going gains a durable completion condition, failures stay
visible, and Home Assistant upgrades follow the installed repository.

## Web

- **Model search.** The picker searches provider names, display names and
  model ids. Exact and partial matches rank above fuzzy ones, and models stay
  grouped by provider.
- **Themes.** Settings now has General and Appearance tabs. Color mode can be
  Auto, Light or Dark, and color palettes follow that choice. A change in one
  tab updates every other open tab.
- **Keep going until….** The mode control has an editable completion
  condition. jep repeats it on every continuation and calls `jep-end-turn`
  when it is met, or explains the blocker when it cannot be. The condition
  survives restarts.
- **Live transcript.** Streamed text is reconciled with saved history instead
  of being replaced on idle, so the last lines no longer flicker or disappear
  while the daemon writes the turn to disk.
- The terminal re-checks access each time it opens and explains how to enable
  it when disabled; running commands are listed above the prompt. A failed
  turn keeps its provider error under the message with Edit and Retry intact.
  Running tools show elapsed time, quotes are visually distinct, and compact
  mode and sidebar dragging no longer crash. The details column can be
  dragged and shows a workspace's folder, branch, diffs and files.

## Daemon and harnesses

- Automatic continuations, retries and resumed turns use the conversation's
  current model, so a model chosen in the picker survives a keep going loop
  and a daemon restart.
- The launcher reads an optional operator env file on every restart
  (`${XDG_CONFIG_HOME:-$HOME/.config}/jep/daemon.env`, or `JEP_ENV_FILE`).
  `JEP_TERMINAL=1` enables interactive terminals there; each device still
  needs the pairing code to unlock one.
- OpenCode compaction always names the conversation's model, including nested
  ids such as LiteLLM's `go/kimi-k3`. Message and part snapshots reach the
  right conversation even when the session id is only on the nested object.
- Codex error items report their real message without failing an otherwise
  successful continuation. Image inputs Codex puts before a user's words are
  recovered as attachments, while quoted `<image>` markup stays in the text.
- Keep going outages back off and are reported once, then rarely. A person
  typing during an outage is answered first without ending the run, and
  sending after Stop releases a held keep going or relentless conversation.

## Home Assistant

- The addon image comes from the repository that was installed, so an upgrade
  does not silently switch to upstream.
- Grouped addon settings replace the flat form, and an older model string no
  longer blocks saving. The image publishes when the addon version moves
  ahead of the package.

## Install

- **Daemon:** `npm install -g https://github.com/tinybig-ai/jep/releases/download/v0.5.0/tinybig-ai-jep-0.5.0.tgz`.
  npm registry publication is separate and needs publisher credentials.
- **Android:** install `jep-0.5.0.apk` from this release.
- **macOS:** unzip `JepBar-0.5.0.zip`; first launch uses right-click → Open.
- **Home Assistant:** add `https://github.com/tinybig-ai/jep` to the app
  store, install Jep, enter model credentials and open the sidebar.
- **iOS:** build from source in Xcode; no TestFlight or App Store build yet.
